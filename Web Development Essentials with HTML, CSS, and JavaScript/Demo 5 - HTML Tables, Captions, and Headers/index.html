Web Development Basics

Introduction

Learning Web Development

Web development combines content, presentation, and behaviour.

Core Technologies

Each technology contributes a different part of a web page.

  • HTML structures page content.
  • CSS controls presentation and layout.
  • JavaScript adds interactive behaviour.

Practice Workflow

Follow these steps when making a small HTML change.

  1. Edit the HTML file.
  2. Save the changes.
  3. Check the browser output.

Comparing Web Technologies

Primary roles of HTML, CSS, and JavaScript

HTML Structure and meaning Headings and paragraphs
CSS Presentation and layout Colours and spacing
